# 2026-09-25～10-11 團體旅遊比價（8 家台灣旅行社）

## 內容
- `tours.json` — 64 筆行程原始資料（旅行社、行程名稱、出發日期、目的地、團費起價、團況、備註、行程連結）
- `build_xlsx.py` — 從 `tours.json` 生成比價試算表的腳本
- `tour-deals-2026-0925-1011.xlsx` — 生成的比價表（已上傳 Google Drive「Muse」資料夾）
- `push_to_github.py` — 把本目錄檔案推上此 repo 的腳本

## 產生方式
```bash
python3 build_xlsx.py
```

## 備註
- 資料來源：鳳凰旅遊、喜鴻假期、五福旅遊、雄獅旅遊、品冠旅遊、山富旅遊、可樂旅遊、理想旅遊 官網
- 查詢時間：2026-09-16（團況與機位為查詢當下即時狀態，會變動）
- 團費皆為每人「起」價，多以雙人一室計價；單人房差各官網多未標示，需直接洽詢旅行社
- 黃色標示 = 已成團／保證出團；9/25-9/28 中秋連假、10/9-10/11 雙十連假團價較高
- 純研究，未報名、未付款、未填寫任何個人資料
